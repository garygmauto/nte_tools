# NTE (Neverness to Everness) Automation Tools

This repository currently only features an **Auto-Fishing** script. Future tools may be added if other tasks become too tedious.

## NTE Auto-Fishing Script

**Specifications:**

- **Platform**: PC Only.

- **Operation**: Foregrounds only (the game window must stay active).

- **Security**: I have provided a pre-packaged .exe file. If you have security concerns, feel free to package the script yourself using Python.

### How to Use

*Please refer to the image tutorial included within the script for visual guidance.*

1. **Configure Zones**: On the script panel, click the buttons from top to bottom to select the following areas:

  - **F Key / Hook Zone**: The area where the interaction prompt appears.

  - **Progress Bar Zone**: The sliding bar area used for reeling/battling the fish.

  - **Settlement Zone**: The area where you click to confirm catch/rewards.

2. **Preview**: Use the "Preview" button to confirm all selected areas are correctly positioned.

3. **Hotkeys (Optional)**: Set up your preferred hotkeys for starting/stopping.

4. **Start**: Click "Start" and switch back to the NTE game window within **2 seconds**.

5. **Relax**: Sit back and wait for the fish to roll in.

**Important Note:**

Ensure you have enough **bait** equipped before starting the script.

### Efficiency & Performance

Based on my current testing:

- **Catch Rate**: ~198 fish in 60 minutes.

- **Income**: ~3,926 coins per hour.
