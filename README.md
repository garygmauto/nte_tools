# 异环 (NTE) 自动化工具

本项目目前仅包含 **自动钓鱼** 脚本。如果后续其他玩法过于繁琐，会考虑更新其他工具。

## 异环自动钓鱼脚本

### 核心特性

- **适用平台**：PC 端。

- **运行方式**：前台运行（需保持游戏窗口在最前端）。

- **安全性**：已封装为 .exe 文件，方便直接使用。如果你有安全顾虑，也可以根据源码自行使用 Python 打包。

### 使用方式

*请参考脚本内的图片教程进行操作。*

1. **框定区域**：在脚本面板上，按顺序从上到下点击按钮进行截屏框选：

  - **F 键区域**：用于检测鱼儿咬钩。

  - **钓鱼进度条区域**：用于遛鱼时的左右滑杆识别。

  - **结算点击区**：用于钓鱼成功后自动点击收鱼。

2. **预览确认**：框定完成后，点击“预览框选区域”确认位置是否准确。

3. **热键设定（可选）**：根据个人习惯设定启动/停止热键。

4. **开始运行**：点击“启动脚本”后，在 **2 秒内**切回到《异环》游戏窗口。

5. **挂机收鱼**：脚本会自动运行，此时你可以去做其他事情。

### 注意事项

- **鱼饵储备**：请在开始前确认角色已装备足够的鱼饵，否则脚本无法持续运行。

### 运行实测

根据目前的版本测试，挂机效率如下：

- **效率**：60 分钟约钓起 **198 条鱼**。

- **收益**：每小时约获得 **3926 个代币**。
